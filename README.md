# シルテム概要（S.Y.L.T.E.M.）

オリジナルSFロボット作品の公式サイト。STORY・CHARACTER・RELATIONSHIP・MECHANIC・GALLERY・DATABASE・COMIC・MUSIC・GAMEを閲覧できます。

人物切り替え、画像拡大、用語検索、任意で開始するOBLIVION侵入演出に対応。HTML・CSS・JavaScriptで動く静的サイトです。

公開先: https://kurogane1008.github.io/syltem/index.html
公開サーバー: GitHub Pages（mainブランチ / ルート）

紹介文は、導入のあらすじ・人物の基本的な役割や性格・世界観を中心に構成しています。相関図は、初期状態でネタバレ防止がONです。OFFにすると、保存されている全ての関係と詳しい説明を表示します。その他の紹介文では、先の展開や事件の解決条件を明かす補足を避けています。サイト用キャッチコピーやOBLIVION画面のログは、本編の確定台詞ではありません。
